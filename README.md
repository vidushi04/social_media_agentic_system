# Agentic Social Media Booster 🚀

Welcome to the **Agentic Social Media Booster** — an AI-powered co-pilot designed to help new content creators break through the noise, manage emotional burnout, and consistently improve their craft to reach their first 1,000 followers.

## What is this?
Growing an audience on YouTube is overwhelming. There is too much conflicting advice, too much data to analyze, and too much pressure to perform. 

This application uses a **Multi-Agent AI System** to take the burden off your shoulders. Instead of just showing you a dashboard of raw numbers, it actually *thinks* about your content and teaches you how to improve, one step at a time.

### How the Agents Help You:
When you paste a link to your latest YouTube video, our team of AI agents go to work behind the scenes:
1. 📊 **Performance Interpreter:** Connects to the live internet and fetches your video's real views, likes, and comments.
2. 🔍 **Content Deconstructor:** Analyzes how you "packaged" your video (your Title, Category, and emotional hooks).
3. 💬 **Audience Signal Reader:** Reads your audience's comments to detect hidden patterns, shifting expectations, or unmet needs.
4. 🧠 **Pattern Detector:** Looks at all the data together to figure out exactly *why* this video performed the way it did.
5. 🎯 **Skill Coach:** Translates everything into **one specific, actionable micro-skill** for you to practice in your next upload.

No more overwhelming "Top 10" lists of generic advice. Just one hyper-focused skill, tailored exactly to your recent content.

## Getting Started

### 1. Run the Application
Make sure you have [Node.js](https://nodejs.org/) installed, then run the following commands in your terminal:

```bash
# Navigate into the web directory
cd web

# Install the dependencies
npm install

# Start the development server
npm run dev
```

### 2. Analyze Your Content
Open your browser and navigate to `http://localhost:5174/` (or the port shown in your terminal). 
1. Paste a link to one of your YouTube videos.
2. Click **Analyze**.
3. *(Optional)* Click the gear icon in the bottom right corner to open **Dev Mode** and watch the Intelligence Engine work in real-time!

# Knowledge Design

Overview
Knowledge design in The Content Mirror is organized around a core principle: **each agent knows what it needs to perform its specific behavior, and nothing more.** Knowledge is scoped to prevent agents from drifting into each other's responsibilities.

## Knowledge Inventory by Agent

### 1. Content Deconstructor — Craft Element Taxonomy
- **What it includes:** Structural vocabulary for YouTube content (thumbnail composition, title formats, opening hook patterns, retention devices, end screen conventions, chapter pacing). Format-specific structural norms.
- **What it excludes:** Performance benchmarks, algorithm explanations, creative advice, or examples from other creators.
- **Why scoped this way:** Outcome-blindness preserves analytical neutrality.
- **Curation sources:** Creator education content from platform-official resources (YouTube Creator Academy), supplemented with structural analysis from content craft practitioners. Explicitly excluded: "go viral" guides.

### 2. Performance Interpreter — Metrics Glossary + Interpretation Framework
- **What it includes:** Complete metric definitions for YouTube (Long-form, Shorts, Community Posts). A metric interpretation framework: ~20 metric-combination-to-meaning mappings (e.g., high shares + low impressions = reference value, weak discoverability). Statistical methods for baseline computation.
- **What it excludes:** Industry-wide benchmarks, algorithm explanations, craft element analysis, growth strategy recommendations.
- **Why scoped this way:** The system's value is in self-referential trend analysis, not comparative ranking.
- **Curation sources:** YouTube Analytics help center documentation.

### 3. Pattern Detector — Pattern Library + Cross-Post Comparison Methods
- **What it includes:** A taxonomy of ~25 common content patterns across hook types, structure approaches, CTA formats, and audience response types. Cross-post comparison methods. Evidence thresholds (3-post minimum).
- **What it excludes:** Skill recommendations, qualitative data analysis, individual post analysis.
- **Why scoped this way:** The Pattern Detector's value is in aggregation and longitudinal analysis.

### 4. Skill Coach — Micro-Skill Library
- **What it includes:** ~30 learnable micro-skills organized by craft dimension (Hooks, Structure, Visuals, CTAs, Copy, Audience Interaction). Each skill includes definition, underlying principle, structural template, and common pitfalls.
- **What it excludes:** Platform-specific growth tactics ("post at 9am"), creative direction, metric targets.
- **Why scoped this way:** The Skill Coach teaches craft, not strategy.
- **Curation sources:** YouTube Creator Academy's craft modules, writing and visual communication pedagogy, and filmmaking fundamentals adapted for YouTube (pacing, open loops, cold opens).

### 5. Audience Signal Reader — Signal Taxonomy + Clustering Methods
- **What it includes:** A classification system for 5 types of audience engagement signals (request, identity, depth, disagreement, community). Thematic clustering methods for grouping disparate comments into themes. Temporal comparison methods for detecting shifts in audience behavior over time.
- **What it excludes:** Sentiment scoring, content recommendations, individual commenter profiling.
- **Why scoped this way:** Focuses on thematic patterns, not sentiment, as sentiment analysis is reductive for YouTube comments.

### 6. Confidence Tracker — Skill Progression Framework
- **What it includes:** A 4-stage progression rubric (Unconscious absence → Conscious awareness → Active practice → Consistent integration) applied per skill dimension. Growth visualization templates. Criteria for milestone identification.
- **What it excludes:** Comparative benchmarks, motivational messaging library, predictions or projections.
- **Why scoped this way:** The Confidence Tracker builds motivation through evidence, not through empty praise. The system earns the creator's engagement by showing concrete facts of their own growth.
